# Dashboard UX Review

- Desktop `/dashboard`: shared quick-access strip is visible below the header and supports horizontal overflow without expanding the page height.
- Desktop `/staff`: persistent grouped sidebar is visible with Workspace, Transformation, and Operations sections; assignment content remains readable in a compact two-column layout.
- Desktop `/admin`: shared role-aware quick-access strip is visible below the observatory heading and the admin page remains scannable without removing existing tools.
- Mobile `/dashboard`: the quick-access strip is horizontally scrollable, preserving access to routes without wrapping the full page; the dashboard header and tabs remain within the viewport.
- Mobile `/staff`: the shared collapsible sidebar pattern switches to the compact sticky mobile header with the active workspace label and language selector.
- Mobile `/admin`: the admin quick-access strip is horizontally scrollable and the observatory heading remains readable at the narrow breakpoint.
- The privacy consent overlay is present in all captures and is pre-existing site chrome; it covers some lower content but does not indicate a dashboard layout defect.
