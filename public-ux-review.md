# Public UX Review

The refined public pages preserve the Executive Observatory design direction: deep navy hero fields, ivory reading surfaces, antique-gold signal accents, editorial typography, asymmetric content columns, and restrained motion. Desktop review covered the homepage, About, Services, School Solutions, Resources, Insights, Contact, and course catalog routes. Each page has a clear hero, breadcrumb context, primary CTA, structured content sections, internal links, and a consistent footer.

At the 390px mobile breakpoint, the public header collapses to a clear logo-plus-menu control, breadcrumbs wrap without horizontal overflow, hero type remains legible, and the form layout stacks into a usable single column. The privacy consent panel is existing global chrome and covers lower viewport content in the screenshots; it is not part of the new page layout.

The new Insights page explicitly states that no articles are published yet, avoiding invented authors or editorial claims. The Contact page preserves the live inquiry mutation, category selection, arithmetic verification, consent, clear success state, error state, and supplied contact channels.
